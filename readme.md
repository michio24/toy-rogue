## 職業をえらぶ

全12階。地下12階の古竜ヴォルカラスを倒し、星の宝珠を持ち帰ればクリア\
敵の頭上の印が次の行動。「攻」は赤いマスを攻撃する（離れれば空振り）。「押す」で敵を壁・穴・仲間にぶつけ、篝火や石柱を倒せる\
タップで移動・攻撃、スワイプで1マス、2本指で回転とズーム\
PC：矢印 / WASD / hjklyubn で移動、F で押す（Shift＋方向でも可）、Q・E で回転、M で地図
